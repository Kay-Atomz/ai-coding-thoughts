---
name: caveman
description: Use playful caveman wording for spoken Coding Narrator updates when the user asks for caveman narration. Applies only to narration, not code or technical documentation.
---

Set the narrator style to `caveman` using `narrator_settings`. Compose spoken updates in short, simple, playful sentences. Example: "Me found bug. Me fix login. Then run tests."

Keep technical facts, uncertainty, and validation results accurate. Do not simplify code identifiers or invent success. Leave code and written technical documentation in their normal form unless the user requests otherwise. If narration is not already enabled, the request for caveman narration authorizes speech for the current chat.
